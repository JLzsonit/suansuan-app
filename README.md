# 算算星球

儿童三科（数学 / 语文 / 英语）学习练习 App，基于 uni-app（Vue3 + Vite），纯本地存储、无需账号，自用版本。

## 功能

- **数学（1-6 年级）**：加减乘除、四则混合、凑十/破十法、进位退位、连加连减、括号混合、有余数除法、比大小、填空、判断、单位换算、小数加减、分数加减，按年级课标综合出题
- **语文（1-6 年级）**：反义词、选读音、量词、古诗填空、近义词、成语填空
- **英语（3 年级起）**：字母练习、看图识词、单词翻译、缺字母、选词填空
- **趣味游戏**：限时挑战（60 秒连击）、气球抢答、数字对对碰、天平砝码、翻牌记忆
- **学习管理**：错题本（自动收录、重练）、每日打卡、练习统计、家长设置（音效、护眼、自动跳题、每日目标）
- **家长控制**：专注锁定（无障碍服务自动拉回）、先学再看（做题换观看时间）、家长远程控制

## 运行

```bash
npm install
npm run dev:h5     # H5 预览
npm run build:h5   # H5 构建
npm run build:mp-weixin  # 微信小程序构建
```

技术栈：uni-app 3 / Vue 3 / Vite 5，题目全部由本地引擎生成，无任何网络请求。

## 安卓安装：先看这一节，能省掉 90% 的麻烦

### 问题：无障碍开关打不开 / 打开了马上又自己关掉

这是 **Android 13（API 33）起的「受限设置」**在拦，跟 APK 本身有没有问题无关。

系统的判定依据是 **安装来源**，不是代码：

| 安装方式 | 系统判定 | 无障碍开关 |
|---|---|---|
| 应用商店安装 / 会话式安装（session-based） | 可信 | 正常，可直接开 |
| 文件管理器、微信、QQ、浏览器、`adb install` 直接装 | 侧载 | **被锁**，开关点了没反应或变灰 |

被锁住时的两个表现：
1. 点开关弹出「出于安全考虑，此设置当前不可用」；
2. 开关是灰的，点不动。

### 解法 A（推荐，一次搞定）：用安装脚本装，伪装成应用商店安装

```bash
# Windows：把 apk 放项目根目录，双击
tools\install-apk.bat

# macOS / Linux
bash tools/install-apk.sh ~/Downloads/app-debug.apk
```

脚本实际执行的是：

```bash
adb install -r -i com.android.vending app-debug.apk
adb shell cmd appops set cn.zsonit.suansuan ACCESS_RESTRICTED_SETTINGS allow
```

`-i com.android.vending` 把安装者标记成 Google Play，系统就不再按侧载对待；
第二条命令直接放行受限设置（兜底，部分机型需要）。

**好处**：开关一次就能打开，之后每次覆盖安装新版本也不会再被系统关掉。

前提：电脑装了 `adb`（Android Platform Tools），手机开了「开发者选项 → USB 调试」并允许调试。

### 解法 B（没有电脑，手机上操作）：手动允许

1. 系统设置 → 应用 → 找到「算算星球」（部分机型：应用管理 / 应用列表）
2. 点右上角 **⋮** → 「允许受限制的设置」→ 用锁屏密码/指纹确认
3. 回到 系统设置 → 无障碍 → 已下载的服务 → 「算算星球 · 专注锁定」→ 打开开关 → 弹窗点「允许」

> 如果 ⋮ 里没有「允许受限制的设置」：先去无障碍页点一次开关，弹出提示框点「确定」，
> 系统会自动跳回应用信息页，这时 ⋮ 菜单里就有了。

**注意**：这种方式每次覆盖安装新版本都要重做一遍。

### 解法 C（干脆不用无障碍）：备用监控

App 内「设置 → 备用监控」：授权「使用情况访问」+「悬浮窗」，用 2 秒一次的前台应用巡检代替无障碍，
同样能在孩子切走时拉回练习页。

### 各家 ROM 的菜单路径

| 品牌 | 无障碍入口 | 允许受限设置的位置 |
|---|---|---|
| 原生 / Pixel | 设置 → 无障碍 → 已下载的服务 | 设置 → 应用 → 算算星球 → ⋮ |
| 小米 / Redmi / POCO | 设置 → 更多设置 → 无障碍 | 设置 → 应用设置 → 应用管理 → 算算星球 → ⋮ |
| 华为 / 荣耀 | 设置 → 辅助功能 → 无障碍 | 设置 → 应用 → 应用管理 → 算算星球 → ⋮ |
| OPPO / 一加 / realme | 设置 → 系统设置 → 无障碍 | 设置 → 应用管理 → 应用列表 → 算算星球 → ⋮ |
| vivo / iQOO | 设置 → 快捷与辅助 → 无障碍 | 设置 → 应用与权限 → 应用管理 → 算算星球 → ⋮ |
| 三星 | 设置 → 辅助功能 → 已安装的应用 | 设置 → 应用程序 → 算算星球 → ⋮ |

### 其他常见「服务起来了但不生效」

- **省电策略杀后台**：设置 → 电池 → 算算星球 → 不限制 / 允许后台活动；国产 ROM 还要打开「自启动」。
- **覆盖安装后开关自动关闭**：系统行为，属正常。用解法 A 安装可避免。
- 排查时打开 App 内「设置 → 检修日志」，复现一次后导出，日志里会记录
  `a11y`（无障碍连接/断开、服务配置）、`kiosk`（锁定开关）、`pull`（拉回）、`remote`（云端指令）。

## 无障碍实现说明

`android/app/src/main/res/xml/kiosk_accessibility_config.xml` 的配置项直接决定
「系统设置里这个开关能不能打开」，几项关键值的取舍写在该文件的注释里，改动前请先看注释：

- `accessibilityEventTypes` 必须同时含 `typeWindowStateChanged` 和 `typeWindowsChanged`
- `canRetrieveWindowContent="true"` + `flagRetrieveInteractiveWindows`（部分 ROM 据此判定服务可用性）
- `isAccessibilityTool="true"`（Android 14+ 区分无障碍工具/自动化工具；Android 16「高级保护」下缺失会被直接禁止启用）
- `KioskService.onServiceConnected()` 内部任何异常都不能抛出，否则系统会把服务判为启动失败并自动关掉开关；
  亮屏广播注册在 Android 13+ 需显式指定导出性（`RECEIVER_NOT_EXPORTED`，异常时降级 `RECEIVER_EXPORTED`），
  并逐级兜住异常
